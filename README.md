# MovieLens Recommender

Production-style movie recommender on the MovieLens 25M dataset.
ALS collaborative filtering, chronological evaluation, FastAPI +
Streamlit, containerised deploy.

> Repo is being scaffolded. Full documentation coming in a later
> commit. See `requirements.txt` for the dependency plan.

## Planned

- Data loader with time-based train/test split
- Popularity baseline + implicit ALS model
- Precision / Recall / NDCG @ K evaluation
- MLflow experiment tracking
- FastAPI backend, Streamlit frontend
- Docker deploy for Hugging Face Spaces
